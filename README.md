# Sports Agent App

Cross-platform app for sports agents to manage athlete clients.

Built with **React Native + Expo** so it runs on:
- Web
- iOS
- Android

## Features (starter)

- Client (athlete) roster with profiles
- Deal / endorsement tracking
- Schedule / calendar of events
- Contract notes & status
- Dark theme, mobile-first UI

## Getting Started

```bash
npm install
npx expo start
```

Then press:
- `w` for web
- `a` for Android
- `i` for iOS (requires Mac + Xcode / Simulator)

Or scan the QR code with the Expo Go app.

## Tech Stack

- React Native
- Expo SDK ~51
- React Navigation (bottom tabs)
- Mock data (easy to replace with real backend / Supabase / Firebase)
